# Abreham Melese

### AI & LLM Engineer · Agents, RAG, Observability, MCP, Multimodal AI, Efficient Language Models

[Portfolio](https://portifolio-fawn-pi-85.vercel.app) · [LinkedIn](https://www.linkedin.com/in/abrehammelese/) · [Email](mailto:xvimelese@gmail.com)

I build AI systems end to end — from retrieval and agent orchestration to evaluation, observability, tool interfaces, and developer workflows. My recent work focuses on production-minded LLM applications, multimodal agents, MCP infrastructure, and resource-efficient language models.

I like taking ambiguous problems, turning them into working systems, and then making the systems easier to inspect, evaluate, and improve. The interesting problems aren't the ones with clean benchmarks; they are the ones where latency, evaluation, and reliability decide whether a model actually ships or just demos well.

### Projects

**[EnterpriseRAG](https://github.com/truecallerabreham/Enterprise-RAG-For-teams)** Cross-repository code intelligence for engineering teams. Index repositories, retrieve relevant symbols with hybrid search + graph expansion, rerank evidence, and return answers with validated source citations. `Python` `FastAPI` `LangGraph` `Tree-sitter` `Qdrant` `BM25` `Neo4j` `RAG`

**[SmartGuard](https://github.com/truecallerabreham/Smart_cctv)** A multimodal incident-auditing agent that turns long CCTV recordings into searchable evidence. Frame-level VLM captioning, semantic search over footage, MCP tool-use, ffmpeg clip extraction. `Multimodal AI` `VLM` `MCP` `FastAPI` `Pixeltable` `Opik` `ffmpeg` `React`

**[LLM Observability & Eval Dashboard](https://github.com/truecallerabreham/llm-observability-dashboard)** A self-hosted stack for seeing what LLM applications are doing after deployment — traces, evaluation scores, drift signals, and operational alerts in one place. `OpenTelemetry` `LLM Evals` `DeepEval` `RAGAS` `ClickHouse` `Prometheus` `Next.js`

**[Arc - Architecture Canvas](https://github.com/truecallerabreham/Vibe)** A developer tool that starts with a system idea, finds structurally relevant open-source projects, turns their real file trees into diagrams, and lets engineers compose and critique an architecture before writing code. `TypeScript` `React` `React Flow` `CLI` `GitHub Search` `LLM`

**[Clipagent](https://github.com/truecallerabreham/Clipagent)** A video search and clip extraction tool. Upload videos, ask questions in natural language, and extract clips by text or image similarity. `FastMCP` `Pixeltable` `FastAPI` `React` `Docker`

**[Telecall](https://github.com/truecallerabreham/Telecall)** An AI voice mobile-carrier assistant that replaces call-center agents. LangGraph + Groq + FastRTC + Twilio + Qdrant for plan inquiries, billing, and technical support. `LangGraph` `Groq` `FastRTC` `Twilio` `Qdrant` `STT` `TTS`

**[Advanced RAG From Scratch](https://github.com/truecallerabreham/Advanced_RAG_From_Scratch.)** Building RAG 2.0 from scratch — from keyword search to MultiModal RAG. `Python` `RAG` `Retrieval` `Multimodal`

**[Forla](https://github.com/truecallerabreham/FLORA)** An async-first framework for transparent agents, multi-agent systems, and deterministic workflows in Python. Visible agent loop, typed protocol, persistent memory, middleware. `Python` `Agents` `Framework` `Async` `Multi-Agent`

**[DigitalOcean MCP Server](https://github.com/truecallerabreham/mcp-server-digitalocean)** MCP server for DigitalOcean infrastructure — manage Droplets, databases, domains, regions, and account information through a structured tool interface. `MCP` `TypeScript` `DigitalOcean` `API`

**[Context Visualizer](https://github.com/truecallerabreham/preflight_contex)** A local proxy for coding-agent model requests that visualizes context blocks, shows token counts and cost, and lets you edit blocks before sending. `TypeScript` `Context Engineering` `Developer Tools`

**[Fraud Detection System](https://github.com/truecallerabreham/fraud_detection_system)** End-to-end ML fraud detection system with full MLOps practices — notebooks, modular source, tests, Docker, GitHub Actions. `Python` `MLflow` `Docker` `CI/CD`
